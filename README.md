# 도토리 마을

느긋하게 사는 작은 마을 이야기. 웹 브라우저에서 바로 돌아가는 3D 마을 생활 게임입니다.

- **실행**: https://dltkdwhdhkd-design.github.io/dotori-village/
- **모델 구경**: https://dltkdwhdhkd-design.github.io/dotori-village/viewer.html
- **물고기·곤충 전 종 펼쳐 보기**: [물고기](https://dltkdwhdhkd-design.github.io/dotori-village/catalog.html?b=fish) · [곤충](https://dltkdwhdhkd-design.github.io/dotori-village/catalog.html?b=bugs) · [꾸미기](https://dltkdwhdhkd-design.github.io/dotori-village/catalog.html?b=looks)
- 주인공은 동물의 숲풍으로 꾸밀 수 있으며, 주민은 치이카와(원작 나가노) 등장인물을 팬 모델로 재현했습니다.

## 할 수 있는 것

- 실제 시계와 이어진 하루: 아침·낮·저녁·밤, 봄·여름·가을·겨울(벚꽃, 단풍, 눈), 맑음·흐림·비·눈
- 낚시(80종: 민물 40 · 바다 40), 곤충 채집(80종), 화석 캐기(12점), 조개 줍기, 과일 따기, 꽃 심고 물 주기, 나무 심고 베기
- **천막에서 시작해 마을 키우기**: 이웃 2명과 천막 좌판뿐인 마을에서, 나무와 돌을 모아 내 집·가게·박물관·다리를 세우고 새 이웃을 맞이해 마을 잔치까지
- 수첩(N): 지금 할 일, 날마다 바뀌는 일감 다섯 개, 도전 과제
- 이웃 주민 12명: 성격별 대사, 부탁, 선물, 친밀도, 편지
- 만물상(사고팔기, 날마다 바뀌는 물건), 박물관(기증·감정, 화석관·곤충관·민물 수족관·바다 수족관), 마을회관(집값·증축)
- 내 집 꾸미기: 가구 41종, 벽지·바닥재 16종, 창고
- 도감, 지도, 우체통, 게시판, 저장(브라우저)·내보내기·가져오기
- **같이 하기**: 메뉴에서 문을 열면 방 코드가 나오고, 친구가 그 코드로 내 마을에 놀러 온다(8명까지). 서로의 모습·몸짓·말풍선이 보이고 같이 낚시하고 채집한다
- **주인공 꾸미기**: 얼굴형 3 · 눈썹 3 · 코 3 · 머리 모양 15 · 눈 8 · 입 5 · 옷 7 · 모자 7 · 안경 3과 피부·머리·옷 색. 이사 준비, 집 안 거울, 메뉴의 ‘캐릭터 꾸미기’에서 얼굴을 확대하거나 모델을 돌려 보며 고른다
- 광장 작업대에서 도구 5종과 가구 13종을 만들 수 있다. 이웃 마을의 일손을 돕거나 토벌 의뢰를 마치면 추가 도안을 배운다. 가방에서 가구를 골라 실내와 야외에 놓고 방향을 바꾸거나 회수할 수 있다.
- 광장 게시판, 부두, 메뉴의 **마을 여행**에서 풀잎 들녘·동굴 등불 마을·라멘 골목에 다녀온다. 들녘의 노동 갑옷 씨에게 의뢰를 받고 랏코나 하치와레와 함께 솜뭉치 괴이를 몰아낸 뒤 보고하면 보수를 받는다.
- 여행지와 캠핑장에서 이웃을 초대할 수 있다. 집터를 골라 실내 꽃 화분을 납품하고 근처 마당에 통나무 걸상을 놓으면 다음 날 이사 온다. 지도의 번호로 집터를 찾을 수 있다.
- 집을 지은 뒤 **메뉴 → 섬 공사**에서 공방과 캠핑장 위치를 직접 정할 수 있다. 마을 잔치를 마치면 흙길·돌길·물길·절벽을 만들고 잔디로 복원할 수 있다.
- 마을 이름과 솜뭉치 괴이, 토벌 의뢰는 이 게임의 창작 설정이다. 생활과 주민 초대는 [닌텐도의 섬 발전 가이드](https://www.nintendo.com/kr/news/article/77otbivgUusCmTTfAjcXwO), 주민의 역할은 [치이카와 공식 캐릭터 소개](https://www.anime-chiikawa.jp/chara.html), 랏코의 검은 [공식 상품 후면 사진](https://chiikawamarket.jp/products/4582662984219)을 참고했다.
- 옷 입은 인형 체형의 캐릭터(눈 깜박임, 말할 때 입 움직임), 해 그림자, 계절마다 바뀌는 잔디

## 조작

| 키 | 하는 일 |
| --- | --- |
| W A S D / 방향키 | 걷기 (Shift: 달리기) |
| G | 가까운 주민을 바라보고 말 걸기 |
| Space / Z / Enter | 잠자리채 휘두르기, 도구 쓰기, 문 열기, 나무 흔들기 |
| F / X | 줍기, 꽃 꺾기 (집 안: 가구 집어넣기) |
| E / I / Tab | 가방 |
| 1~5, Q, 0 | 도구 꺼내기 / 차례로 바꾸기(집 안: 가구 돌리기) / 집어넣기 |
| N, C, M, Esc | 수첩, 도감, 지도, 메뉴 |
| T | 말하기(같이 하는 동안) |

잠자리채는 Space를 **누르고 있으면** 살금살금 걷고, **떼면** 휘두릅니다.
개미는 평소에 보이지 않고, 땅에 과일을 놓아두면 그 곁에 모입니다.
화면이 느리면 메뉴(Esc)에서 **해 그림자**를 끄세요(버벅이면 게임이 스스로 끄기도 합니다).
낚시는 물고기 그림자 앞에 찌를 던지고, 찌가 쑥 들어갈 때 Space.

## 폴더

```
index.html, viewer.html, catalog.html   게임, 모델 구경, 생물 전 종 펼쳐 보기
js/core     시계·입력·소리·도구 함수
js/data     아이템, 주민, 대사 (data/*.json: 물고기·곤충)
js/world    마을 지도 만들기, 마을 상태
js/gfx      3D(지형, 물, 모델, 캐릭터, 무대)
js/game     게임 진행(주인공, 주민, 생물, 대본, 창, 하루 갱신)
js/ui       화면 위 글과 창
assets/models   게임용 모델 묶음(.glb)
assets/chars    캐릭터 모델(한 명에 파일 하나) + chars.json
blend/          블렌더 원본(.blend) — 열어서 고칠 수 있음
tools/blender   모델을 만드는 블렌더 파이썬 스크립트
docs/           기획서, 캐릭터 바꾸는 법, 블렌더 작업 안내
vendor/three    three.js (MIT)
vendor/mqtt     mqtt.js (MIT) — 같이 하기에서 중계 서버와 이야기할 때 쓴다
tools/dev       같이 하기를 내 컴퓨터에서 시험할 때 쓰는 중계 서버
```

## 모델을 고치는 두 가지 길

1. **블렌더에서 직접**: `blend/` 안의 파일을 열어 고친 뒤 glTF(.glb)로 내보내 `assets/` 의 같은 이름 파일을 덮어씁니다. → [docs/blender.md](docs/blender.md)
2. **스크립트로**: `tools/blender/*.py` 를 고치고 `python3 tools/blender/build.py` 를 실행하면 `.glb` 와 `.blend` 가 다시 만들어집니다.

캐릭터를 바꾸는 방법은 [docs/characters.md](docs/characters.md), 전체 기획과 다음 할 일은 [docs/design.md](docs/design.md) 에 있습니다.

## 점검용

주소 뒤에 `?auto=1&seed=숫자` 를 붙이면 타이틀을 건너뛰고 그 씨앗의 마을로 바로 시작합니다.
브라우저 콘솔에서 `DV.time('2026-01-15T10:00:00')`(시각 고정), `DV.tp(x, z)`, `DV.give('fish_ingeo')`, `DV.money(1000)`, `DV.day()`(하루 넘기기)를 쓸 수 있습니다.
