# 도토리 마을

느긋하게 사는 작은 마을 이야기. 웹 브라우저에서 바로 돌아가는 3D 마을 생활 게임입니다.

- **실행**: https://dltkdwhdhkd-design.github.io/dotori-village/
- **모델 구경**: https://dltkdwhdhkd-design.github.io/dotori-village/viewer.html
- 캐릭터·이름·대사·그림·음악은 전부 이 게임을 위해 새로 만든 것입니다.

## 할 수 있는 것

- 실제 시계와 이어진 하루: 아침·낮·저녁·밤, 봄·여름·가을·겨울(벚꽃, 단풍, 눈), 맑음·흐림·비·눈
- 낚시(38종), 곤충 채집(33종), 화석 캐기(12점), 조개 줍기, 과일 따기, 꽃 심고 물 주기, 나무 심고 베기
- 이웃 주민 12명(처음 6명, 며칠마다 새 이웃): 성격별 대사, 부탁, 선물, 친밀도, 편지
- 만물상(사고팔기, 날마다 바뀌는 물건), 박물관(기증·감정), 마을회관(집값·증축)
- 내 집 꾸미기: 가구 41종, 벽지·바닥재 16종, 창고
- 도감, 지도, 우체통, 게시판, 저장(브라우저)·내보내기·가져오기
- 옷 입은 인형 체형의 캐릭터(눈 깜박임, 말할 때 입 움직임), 해 그림자, 계절마다 바뀌는 잔디

## 조작

| 키 | 하는 일 |
| --- | --- |
| W A S D / 방향키 | 걷기 (Shift: 달리기) |
| Space / Z / Enter | 말 걸기, 문 열기, 도구 쓰기, 나무 흔들기 |
| F / X | 줍기, 꽃 꺾기 (집 안: 가구 집어넣기) |
| E / I / Tab | 가방 |
| 1~5, Q, 0 | 도구 꺼내기 / 차례로 바꾸기(집 안: 가구 돌리기) / 집어넣기 |
| C, M, Esc | 도감, 지도, 메뉴 |

잠자리채는 Space를 **누르고 있으면** 살금살금 걷고, **떼면** 휘두릅니다.
개미는 평소에 보이지 않고, 땅에 과일을 놓아두면 그 곁에 모입니다.
화면이 느리면 메뉴(Esc)에서 **해 그림자**를 끄세요(버벅이면 게임이 스스로 끄기도 합니다).
낚시는 물고기 그림자 앞에 찌를 던지고, 찌가 쑥 들어갈 때 Space.

## 폴더

```
index.html, viewer.html   게임, 모델 구경 페이지
js/core     시계·입력·소리·도구 함수
js/data     아이템, 주민, 대사 (data/*.json: 물고기·곤충)
js/world    마을 지도 만들기, 마을 상태
js/gfx      3D(지형, 물, 모델, 캐릭터, 무대)
js/game     게임 진행(주인공, 주민, 생물, 대본, 창, 하루 갱신)
js/ui       화면 위 글과 창
assets/models   게임용 모델 묶음(.glb)
assets/chars    캐릭터 모델(한 명에 파일 하나) + chars.json
blend/          블렌더 원본(.blend) — 열어서 고칠 수 있음
tools/blender   모델을 만드는 블렌더 파이썬 스크립트
docs/           기획서, 캐릭터 바꾸는 법, 블렌더 작업 안내
vendor/three    three.js (MIT)
```

## 모델을 고치는 두 가지 길

1. **블렌더에서 직접**: `blend/` 안의 파일을 열어 고친 뒤 glTF(.glb)로 내보내 `assets/` 의 같은 이름 파일을 덮어씁니다. → [docs/blender.md](docs/blender.md)
2. **스크립트로**: `tools/blender/*.py` 를 고치고 `python3 tools/blender/build.py` 를 실행하면 `.glb` 와 `.blend` 가 다시 만들어집니다.

캐릭터를 바꾸는 방법은 [docs/characters.md](docs/characters.md), 전체 기획과 다음 할 일은 [docs/design.md](docs/design.md) 에 있습니다.

## 점검용

주소 뒤에 `?auto=1&seed=숫자` 를 붙이면 타이틀을 건너뛰고 그 씨앗의 마을로 바로 시작합니다.
브라우저 콘솔에서 `DV.time('2026-01-15T10:00:00')`(시각 고정), `DV.tp(x, z)`, `DV.give('fish_ingeo')`, `DV.money(1000)`, `DV.day()`(하루 넘기기)를 쓸 수 있습니다.
