# 다음 단계 계획 (2026-11-19)

마을 생활 게임의 본보기(동물의 숲: 새로운 수평선)를 다시 조사해서, 지금 게임에 빠져 있는 뼈대를 정리하고 만드는 순서를 정했다.
이 문서는 작업 기록을 겸한다. 끝난 항목은 `[x]` 로 바꾼다.

## 1. 조사한 것 (구조만 참고하고, 이름·캐릭터·그림·대사는 가져오지 않는다)

| 본보기의 구조 | 우리 게임에 지금 있는 것 | 고칠 방향 |
| --- | --- | --- |
| 텐트 한 채와 이웃 두 명으로 시작한다. 가게·박물관·다리·집터는 재료와 채집물을 모아 하나씩 세운다 | 처음부터 집·가게·박물관이 다 있고 이웃 여섯이 산다 | **천막에서 시작**, 이웃 2명. 나머지는 할 일을 해내면 생긴다 |
| 생물 5종을 보여 주면 박물관장이 천막을 치고, 15종을 더 기증하면 건물이 선다 | 박물관이 처음부터 있다 | 같은 두 단계로 |
| 박물관은 곤충·물고기·화석 전시관이 따로 있고, 기증한 것이 살아서 전시된다 | 방 하나에 기증 창구만 있다 | 로비 + 곤충관 + 민물 수족관 + 바다 수족관 + 화석관 |

| 날마다 바뀌는 작은 일감 다섯 개와, 오래 걸리는 도전 과제 | 없다 | 수첩(할 일 / 오늘의 일감 / 도전 과제) |
| 시작할 때 피부·머리 모양·머리색·눈·코입·볼을 고르고, 나중에 거울에서 바꾼다 | 정해진 네 가지 모습 | 부위별로 고르는 꾸미기 + 집 안 거울 |
| 도구마다 몸짓이 다르다 | 잠자리채와 삽·도끼가 비슷하게 내려친다 | 잠자리채는 머리 위에서 내려찍기, 삽은 두 손으로 땅에 꽂아 퍼 올리기, 도끼는 옆으로 휘두르기 |
| 친구 섬에 놀러 간다 | 혼자만 | 방 코드로 친구 마을에 놀러 가기(스페이스 크래프트와 같은 방식) |

## 2. 만드는 순서

### A. 도구 몸짓 (`js/gfx/actor.js`)
- [x] 자세 값에 '자루의 어디를 쥐는지(g)', '도구를 옆으로 돌린 각(y)', '자루를 축으로 돌린 각(r)', '몸을 비튼 각(w)' 추가
- [x] 잠자리채: 등 뒤로 젖혔다가 머리 위로 크게 내려찍기
- [x] 삽: 평소엔 날을 아래로 짚고 다님 → 두 손으로 들어 땅에 꽂기 → 젖혀서 흙 퍼 올리기
- [x] 도끼: 몸을 틀어 옆으로 휘두르기
- [x] 물뿌리개: 기울이면 물줄기

### B. 물고기·곤충 (`tools/blender/fishkit.py`, `topkit.py`, `bugkit.py`, `paint.py`, `data/*.json`)
- [x] 물고기: 종마다 옆모습 그림(몸 윤곽, 등·옆구리·배 색, 줄무늬·점·얼룩, 지느러미, 눈)을 그려 몸에 입힌다
- [x] 곤충: 종마다 위에서 본 그림(날개 무늬, 딱지날개 점, 몸 마디 색)을 그려 입힌다. 무리별 몸 틀(나비, 딱정벌레, 메뚜기, 잠자리, 매미, 벌, 노린재 …)
- [x] 게·가재·거북·개구리·가오리·아귀·해파리처럼 위에서 본 모습이 특징인 물속 생물도 같은 방식(`topkit.py`)
- [x] 물고기 80종(민물 40 · 바다 40), 곤충 80종. 사는 곳에 '강 상류' 추가, 곤충이 있는 곳에 '물가·길 위·모래밭' 추가
- [x] 도감을 민물고기 / 바닷물고기 / 곤충 / 화석으로 나눔
- [x] 묶음 파일을 `fish.glb` · `bugs.glb` 둘로 나누고 그림은 webp로 줄여 넣음(합쳐 약 4.5MB)
- 남은 손질: 오징어·문어·해마·달팽이·도롱이벌레는 예전 틀 그대로다. 메뚜기 무리의 등 무늬가 단조롭다.

### C. 박물관 전시관 (`js/game/rooms.js`, `scripts.js`)
- [ ] 방에서 방으로 가는 문
- [ ] 로비, 곤충관(정원), 민물 수족관, 바다 수족관, 화석관
- [ ] 기증한 생물이 전시관에서 움직이고, 앞에서 Space를 누르면 설명이 뜬다

### D. 처음부터 키워 가는 마을 (`state.js`, `daily.js`, `scripts.js`, `mapgen` 은 그대로)
- [ ] 시작: 내 천막, 이웃 2명, 마을회관, 천막 가게. 박물관 터·집터 6곳·둘째 다리는 비어 있음
- [ ] 재료: 나무(도끼질), 돌(바위 두드리기), 나뭇가지(줍기)
- [ ] 할 일 9단계: 첫걸음 → 이웃과 인사 → 생물 5종 → 내 집 → 가게 짓기 → 박물관 15종 → 새 이웃 세 집 → 다리 → 마을 잔치
- [ ] 오늘의 일감 다섯 개(해내면 새 일감), 도전 과제
- [ ] 예전 저장은 '다 지어진 마을'로 이어받는다

### E. 캐릭터 꾸미기 (`tools/blender/chars.py`, `js/game/look.js`)
- [ ] 부위를 갈아 끼우는 주인공 모델: 머리 모양, 눈, 옷, 모자, 안경
- [ ] 피부색·머리색·눈 색·옷 색
- [ ] 시작 화면과 집 안 거울에서 고르기

### F. 같이 하기
- [ ] 방장이 방 코드를 만들고 친구가 그 마을에 들어온다(공개 중계 서버). 서로의 모습·몸짓·말풍선이 보인다
